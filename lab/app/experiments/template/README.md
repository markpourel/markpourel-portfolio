# Шаблон эксперимента

Пустой пример. Скопировать папку в `app/experiments/<имя>/` (латиница,
через дефис), переименовать маршрут, дописать этот файл.

**Имена папок с `_` в начале использовать нельзя:** Next.js считает их
private folders и не маршрутизирует — страница отдаёт 404 (проверено
на `_template`). Поэтому шаблон называется `template`.

## Что проверяем

Одна-две фразы: какой вопрос к библиотеке или приёму. Что должно быть
верно на сайте, чего мы не знаем сейчас.

## Вывод

- Что вышло: подходит / не подходит.
- Размер бандла (если мерили): рост JS первой загрузки.
- Лицензия: совместима с публичным репозиторием или нет.
- Что переносим на сайт (ссылка на правило в `lab/README.md`) и при каком
  Gate, либо почему не переносим.

## Как проверить

```powershell
cd lab
npm ci
npm run dev
# http://localhost:3100/experiments/<имя>/
```
