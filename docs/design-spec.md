# Спецификация дизайна

Источник значений — макет владельца. Файл ведётся на этапе 6: сюда переносятся
токены, типографика, сетка и состояния, а также фиксируются конфликты макета
с доступностью, схемой контента и лицензией шрифтов.

## Временная страница (4Б)

**Статус:** временно, не дизайн-решение, не прецедент для этапа 6.

- Оформление нейтральное: светлый фон (`#ffffff`), тёмный текст
  (`neutral-900`), системный шрифт, без изображений, анимаций, форм
  и счётчиков.
- Текст и контакт — подтверждённые владельцем: имя, роль, одна фраза
  о направлении работы, Telegram `@markpourel`.
- Страница не задаёт ни одного токена этапа 6: палитра, типографика,
  сетка и компоненты будут взяты из макета владельца.
- `canonical` и `og:url` указывают на `https://markpourel.ru/`.

После приёма макета (общий Gate A) этот раздел остаётся только как история:
значения этапа 6 записываются ниже, отдельными разделами.
